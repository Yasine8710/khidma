# Contributing

Khidma is proprietary. External contributions are not accepted without prior written agreement with the owner.

## Workflow (authorized contributors)
- `main`: stable. `develop`: integration. Feature branches: `feat/...`, `fix/...`.
- Conventional commits: `feat:`, `fix:`, `test:`, `docs:`, `chore:`.
- Run `dart format .`, `flutter analyze`, `flutter test` before opening a PR.
- Never commit secrets, `.env`, signing files, or personal data.

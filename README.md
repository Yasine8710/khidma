# Khidma · خدمة

A trusted local services marketplace built for Tunisia. Discover professionals, request services and connect with local experts.

## Status
Phase 0 — project initialization. Nothing here is production-ready yet.

## Stack
Flutter (iOS) · Riverpod · GoRouter · Supabase (Postgres, Auth, Storage, RLS) · FCM · FR / AR (RTL) / EN.

## Layout
- `app/` Flutter application
- `backend/` Supabase migrations and config
- `admin/` Admin dashboard
- `docs/` Architecture, plan, schema, security, AI collaboration

## Setup
Copy `.env.example` to `.env` and fill placeholders. Never commit secrets.
